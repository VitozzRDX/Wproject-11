## Архитектура
```
Click → Interpreter (RULES matching) → Engine (handlers) → State
                                             → UIState (event bus) → RendererUI
                                             → Rules (чистая математика)
```

- **State** (state.js) — данные + subscribers. `window.State` доступен.
- **PhaseManager** — фазы: `setup`, `rally`, `prepFire`, `movement`, `defensiveFire`, `advancingFire`, `rout`, `advance`, `closeCombat`.
- **Rules** (rules.js) — чистая математика, НЕ импортит State.
- **Engine** — единственный кто мутирует State.
- **UIState** — event bus.
- **Запрет**: main.js ↔ engine.js прямых импортов нет (новые кросс-модульные хелперы — через новый отдельный файл или UIState-ивент).
- **Слои Konva:**
  - `backgroundLayer` — карта + hex-grid.
  - `ccLayer` — world-anchored под юнитами (CC-подсветка).
  - `unitLayer` — юниты на карте.
  - `worldFxLayer` — LoS, residual, smoke, rout, setup-bounds.
  - `uiLayer` — screen-fixed: кнопки, крутилка, dice, Turn-text, Hill/VP-counter, setup-панель, пул-юниты (во время setup).

## Фазы

### Setup — пре-спавн юнитов
- `setupPhase.js`: `startSetup`, `initSetupSide`, `applyDiceRoll`, `refreshSetupPanel`, `refreshEndSetupSideButton`, `placeFromPool`, `instantUnitMoveFromHexToHex`, `returnToPool`.
- Все юниты стороны спавнятся ОДИН раз в начале фазы (fixed pool) или по ролу (dice outcome).
- Пул-юниты живут на `uiLayer` с `inSetupPool=true`, hex=null, path=[].
- `placeFromPool`: `node.moveTo(unitLayer)`, hex=клик, inSetupPool=false, `path=[{hex, isRoad: Rules._isRoadHex(hex)}]`, вызывает `_updateHexControl`.
- `returnToPool`: обратно на uiLayer, hex=null.
- `instantUnitMoveFromHexToHex`: карта→карта, без tween.
- `recalculateHexInstant(hex)` в positioning — мгновенный стек без tween (используется в setup и saveLoad).
- `State.setupSelectedUnits` — массив 0..3 ID. Выбранные юниты «липнут» к курсору (`_setupStickyCursor` в main.js, offset +1).
- Dblclick в пуле на инфантри — выбирает до 3 того же templateId (`dblClickSetupSelect`).
- `_canPlaceAtHex(uids, hex)`: проверка enemy infantry + setup zone (`_isHexInSetupZone(nation, hex)`) + overstack.
- Правила interpreter: SetupReturnToPool, SetupAttachWeapon, SetupPlaceOrMoveOnHex, SetupToggleSelect. Clicked selected unit (sticky) не считается кликом по панели.
- Setup zone bounds визуализация: `drawSetupBounds(hexes)` на worldFxLayer (зелёная заливка), обновляется при SetupToggleSelect/dblClickSetupSelect/_clearSetupSelection.
- `_clearSetupSelection` восстанавливает позиции (sticky возвращается в пул/стек).
- Клик по RollDice: `applyDiceRoll(roll)` → пул дополняется из outcomes + ставит `State.alliedVpTarget` из `winConditions.atGameEnd.targets[roll]`.

### Rally — полностью готово (без изменений).

### MPh (Movement)
- `_updateHexControl(targetHex)` вызывается в `_apply_movement_result_in_State_for_all_MG`.
- `_portageExcess`: SMC-бонус выдаётся MMC с максимальным excess (не первой в MG).
- `wasExhaustedLastTurn`: в начале MPh (NextPhase p==='movement') вызывается `_applyMPhStartCXCleanup` — у юнитов стороны-атакующего `exhausted=false`, но `wasExhaustedLastTurn=true` (блок DT, см. `checkDoubleTimeCapability`). В конце MPh оба флага чистятся.
- Dblclick в MPh на own-юнита → `dblClickAddingToMovingGroup` (атакер → MG; дефендер → DFF FG).
- Smoke placement: CX допустим (+1 DRM к SE roll).

### PFPh / DFPh / AFPh
- `_handleFire` возвращает `coloredDie`, `whiteDie` → `UIState.showDice(colored, white)` показывает пару кубиков под крутилкой.
- MG weapons в FG: `shakeNode(u.node)` — короткая анимация отдачи (shakeNode в renderer.js).
- PFPh после атаки: снимает `prepFired=true` + `exhausted=false` (A3.2.5).
- Dblclick → `dblClickAddingToFireGroup` для стороны-стрелка (prepFire/advancingFire=attacker, defensiveFire=defender).
- Lasso-рамка (резиновая): mousedown на пустом месте → mousemove тянет Konva.Rect на worldFxLayer → mouseup вычисляет hexesInRect → `interpretLassoRelease(hexes)` диспатчит `dblClickAddingToMovingGroup`/`dblClickAddingToFireGroup` для каждого hex в прямоугольнике.

### RtPh — без изменений.

### APh
- `_updateHexControl(targetHex)` вызывается в handler `Advance`.

## Контроль гексов и VP (A26 + Scenario A win)
- **A26 Control**: Good Order Infantry MMC (type==='squad', !broken/!pinned/!wounded) в hex'е без enemy infantry → её faction получает контроль. Faction: nation ∈ `AXIS_NATIONS` ('german','italian','japanese') → axis, иначе allied.
- `State.hexControl: {"col-row": "axis"|"allied"}`. При loadScenario копируется из `scen.hexControl`.
- `_updateHexControl(hex)` в engine, вызывается после MPh/APh move.
- `_refreshHexControlCounter()` — счёт hex'ов нужного terrain (`winConditions.autoAtTurn4.terrain`) → `UIState.setHillControlText('Hill: Ax N / Al M')`.
- `_calcUnitVP(u)`: squad=2, halfSquad=1; leader lM≤-1 → 2, lM 0/1 → 1; non-axis → 0.
- `_grantAlliedVP(amount)`: добавляет к `State.alliedVP`, обновляет UI, лог победы при `>= alliedVpTarget`.
- Вызовы: `_eliminateWithKIA` → +_calcUnitVP(u); `_replace_unit` при CR squad→halfSquad → +1.
- `_checkWinConditions` вызывается после side-swap/инкремента turn, проверяет `autoAtTurn4` в конце full turn 4.
- VP-условие (atGameEnd) проверяется автоматически при `_grantAlliedVP` — лог при `alliedVP >= alliedVpTarget`.
- UI: `TURN n/m` над крутилкой (y=2); `Hill: Ax n/Al m` под кубиками (y=185); `VP: n/t` под Hill (y=205). При loadScenario и applyDiceRoll setTimeout 100ms (чтобы пул-юниты не легли сверху).

- `_restoreTurnphaseRotation`: idx*(-45°) по фазе.
- `_restoreSmokeVisuals`: пере-дёрнуть setSmoke для каждого hex с 'smoke' в dynamicTerrain.
- `_restoreTurnText`, `_restoreHillCounter`, `_restoreVPCounter` — setTimeout 50-100ms.
- `_restoreSetupPanelIfNeeded`, `_restoreSetupBoundsHighlightIfNeeded` — для setup-фазы.
- Load защищён от undefined hexControl (defensive `?? {}` на старых сейвах).
- Клавиши Save/Load. Load выдан `fadeButton` если `!hasSave()`. После `save()` вызывается `UIState.redrawButton('Load')`.

## Hover / Interaction
- `_raiseHoveredUnit(unitId)`: `moveToTop()` ТОЛЬКО кликнутого (ранее тянул оружие/владельца — отменено).
- `restoreUnitZ(unitId)` в positioning восстанавливает стек через `_stackOrder`.
- Hover-raise подавляется только во время `_dragStart` (lasso). Во время sticky-cursor hover работает параллельно — пул-юниты smещены на +1px.
- Lasso: синий пунктир (dash:[4,2]) на worldFxLayer. mouseup с размером <4px → игнор, иначе `interpretLassoRelease`. click-suppression флагом `_dragWasReal`.
- `interpretEvent` вызывает `UIState.clearLOS()` перед `Engine.execute` (любое сработавшее правило = результативный клик).

## Rules / Mechanics (новое с прошлого контекста)
- `isHexInSetupZone(nation, hex)` в engine: проверка col/row range из `scen.setup.sides[side].bounds` (`{all: {col,row}}` или `{byNation: {nation: {col,row}}}`).
- `_isRoadHex(hex)` safe for null hex (spawn-в-пул пустой path).
- `_isHexInsetupZone` объявлен в engine, используется в `_canPlaceAtHex` и для подсветки setup-зоны.
- `checkOverstack` экспортнута из rules.js, доступна через Rules.
- `calcFireEffect` возвращает `coloredDie, whiteDie` для dice UI.
- `fireAttack` возвращает те же поля.
- `calcLeadershipDRM`, `rollRallyAttempt`, `rollRepairAttempt`, `rollSmokePlacementAttempts` — доступны через Rules.
- `_applyCowering` негирует cowering при ЛЮБОМ лидере в FG (упрощённый ASL).
- Mustrout `openGround` считается если `terrain.every(t => t === 'crestLine')` (crestLine не блокирует).
- `_portageExcess` SMC-бонус идёт MMC с наибольшим excess (учитывая CX).
