## Архитектура
```
Click → Interpreter (RULES matching) → Engine (handlers) → State
                                             → UIState (event bus) → RendererUI
                                             → Rules (чистая математика)
```

- **State** (state.js) — данные + subscribers (fires only on setUnit). `window.State` доступен.
- **PhaseManager** — 8 фаз ASL: `rally`, `prepFire`, `movement`, `defensiveFire`, `advancingFire`, `rout`, `advance`, `closeCombat`. `getPhase()`/`setPhase()`/`next()`.
- **Rules** (rules.js) — чистая математика. Импортит `PhaseManager` (для phase-based правил как FFNAM/FFMO/AFPh halving), НЕ импортит `State`.
- **Engine** — единственный кто мутирует State.
- **UIState** — event bus для UI (кнопки, крутилка, LoS, residual, smoke, rout overlays).
- **RendererUI** подписан на UIState, использует ДВА слоя:
  - `uiLayer` — screen-fixed (кнопки, крутилка). Компенсируется через `uiLayer.x(-stage.x())` при скролле.
  - `worldFxLayer` — world-anchored (LoS, residual, smoke, rout overlays). Скроллится с миром.
- **Renderer** подписан на State.setUnit.
- **Positioning** — стэкинг юнитов в hex'e через offset.

## Coordinate System
- **Единая нумерация `"col-row"`** через всю карту (hexUtils.hexLabel).
- **Origin (0, 1)** = хекс прямо над uB1 в старой системе.
- Пример: `vG8` → new `"38-9"`, `uAC4` → new `"27-5"`.
- `pixelToHex` использует **Voronoi-nearest** (перебор 9 кандидатов) — корректный hex по клику.
- `hexDistance` — cube-based, точное расстояние.
- `_hexLine` (в rules.js) — pixel-based Bresenham + Voronoi + dedup:
  - Фильтр "чирков" (perpDist > R√3/2 + SPINE_TOL).
  - Hex-spine resolution: если LoS ровно по границе, берём hex с бо́льшим hindrance (worst-for-shooter).
- `cubeRing(center, radius)` — hex'ы на кольце заданного радиуса.

## Единая иерархия юнитов (unitloading.js)
```
Unit (base)
├── Infantry (category='infantry')
│    ├── Squad, HalfSquad (Infantry chain по nation/quality)
│    └── Leader (SMC)
└── CarriedItem (category='carried', possessorId)
     └── SW → MG (LMG/MMG/HMG etc., mgClass='LMG'/'MMG'/'HMG')
```

**Роли юнитов:** `unit.side = 'attacker' | 'defender'` — статично per scenario (при turn cycle swap-логика ещё не реализована).

## Реализованные механики

### Движение (MPh)
- Per-unit MF, leaderBonus, roadBonus.
- Woods-Road two-step (UseWoods/UseRoad).
- crestLine (double cost при подъёме).
- Overstack check (3 squads + 4 leaders).
- Split MG.
- Double Time (+2 MF, exhausted).
- Assault Movement (1 шаг, negates FFNAM, cannot use all MF).
- **PlaceSmoke** two-step (own hex = 1 MF, adjacent = 2 MF).
- **Portage Points (dynamic):** `_portageExcess(u, units, mg)` считается динамически при каждом move-check. SMC contribution: каждый Good Order лидер в MG добавляет +1 IPC первому MMC. Drop/pickup weapon → excess пересчитывается в real time.
- **Drop:** button при MG с possessed weapons — дропает всё possessed юнитов MG, ставит `movedThisMPh=true`.
- **Recover:** 1 MF, dr < 6 (+1 CX). Первый годный юнит × первое годное оружие.
- **`_refreshMGButtons()`** — централизованный refresh всех MG-кнопок (DT/AM/PlaceSmoke/Drop/Recover) после add/move/drop/recover.

### Фаза-специфика огня
- **PhaseManager-based:** `calcFFNAM/calcFFMO` возвращают 0 в `defensiveFire` (Final Fire). `calcFirepower` халвит FP в `advancingFire`.
- **Interpreter правила phase-aware:** `phaseIsMovement`, `phaseIsPrepFire`, `phaseIsDefensiveFire`, `phaseIsAdvancingFire`, `phaseIsRout`.

### PFPh (Prep Fire Phase)
- Attacker стреляет по стоящим defender'ам.
- Post-fire: `prepFired=true` (оранжевая "PF" в центре), снимается CX.
- В MPh юниты с `prepFired` не могут двигаться.

### MPh + DFF (Defensive First Fire)
- Полный пайплайн: LoS, TEM, HA, hindrance, FFNAM, FFMO, leadership, IFT, MC/PTC/KIA/K/, cascade LLMC→LLTC.
- SFF/FPF checks вынесены в engine (перед adjacency split): `Rules.checkSFFValid`, `Rules.checkFPFValid`.
- 3.2.2 (`_check_separate_attack`) и 3.3.3 (`_check_shots_exceed_mf`) в `Rules` (принимают `firedFromRecord`).
- Multi-hex FG splitting via `Rules.array_of_adjacent_Hexes_arrays`.
- Residual FP (`_set_residualFP_in_hex` helper) → красная 12-конечная звезда на worldFxLayer. Сбрасывается в конце MPh.
- Cowering, TPBF/PBF/Area, weapon B# malfunction, RoF preservation, ELR quality reduce chain.
- LoS-blocked стрелки считаются выстрелившими (attempt = fire, `_set_firing_Status` использует firegroupUnits напрямую).

### DFPh (Defensive Fire Phase — Final Fire)
- Defender стреляет по всем attacker-infantry в hex'e (независимо от движения).
- `Rules.checkDFPhFinalFireValid`: если FirstFire-стрелок дальше adjacent → вся FG не стреляет.
- FFNAM/FFMO негируются.
- Post-fire: firingStatus → FinalFire.
- End of DFPh: все FirstFire/FinalFire counters сбрасываются.

### AFPh (Advancing Fire Phase)
- Attacker стреляет с half FP (в `calcFirepower`).
- Ограничения в `checkIfAddingToFireGroupIsValid`:
  - `unit.prepFired` → не может.
  - `unit.advFired` → не может.
  - MMG/HMG с `possessor.hasStartedMoving` → не может.
- Post-fire: `advFired=true` (белая полоска снизу + "fired").
- End of AFPh: сброс `prepFired`/`advFired`.

### RtPh (Rout Phase)
- **Идентификация must-rout** при входе в rout (`NextPhase`):
  - `Rules.mustRout(unit, units, orchardInSeason)`: broken + (adj to unbroken enemy) OR (Open Ground + normal range + LoS Good Order enemy).
  - `Rules._isGoodOrderShooter` — helper (unbroken, unpinned, no halved FP, FP≥1).
  - Пометка `mustRout=true` (красная пунктирная рамка).
  - **Кэш на юните**: `keuIDsList` (enemy с LoS до юнита) + `shelterHexes` (потенциальные укрытия).
- **`Rules.buildKEUList(unit, units, orchardInSeason)`** — enemy с LoS. Persistent на весь RtPh.
- **`Rules.findRoutShelter(router, keuUnits)`** — hex'ы forest/building/Woods-Road в радиусе 6 hex через `cubeRing`, не ближе к KEU чем старт.
- **Клик по mustRout юниту → `SelectRouter`:**
  - `mf=6`, `inRouting=true` (жёлтая рамка).
  - Читает закэшированные `keuIDsList`/`shelterHexes`.
  - Подсветка: зелёные легальные adjacent hex'ы (`Rules.legalRoutNeighbors`), синие shelter'ы (`shelterHexes`).
- **Клик по легальному hex'у → `RoutMove`:**
  - Проверка `isLegalRoutStep` (не сокращает range к KEU).
  - Woods-Road auto-treated as woods (cost=2 MF, `usedWoodsRoad=true`).
  - Move + subtract MF + update path.
  - Пересчёт легальных hex'ов из новой позиции.
  - При MF=0: снять `mustRout`/`inRouting`, очистить overlay.
- **End RtPh:** сброс всех mustRout/keuIDsList/shelterHexes/inRouting, очистка overlays.
- **НЕ реализовано:** Interdiction NMC, Low Crawl, attacker-first ordering, auto-end on shelter reach, cannot-rout-eliminated, adjacency-rule.

### Огонь — унифицированный пайплайн `_handleFire` (engine.js)
Общая функция для всех фаз огня (MPh DFF, PFPh, DFPh, AFPh):
1. `getTargets` per phase (movedTargets / defenderInfantry / attackerInfantry).
2. Phase-specific pre-checks (`switch`):
   - MPh: `check_separate_attack`, `check_shots_exceed_mf`, `checkSFFValid`, `checkFPFValid`.
   - DFPh: `checkDFPhFinalFireValid`.
3. `filter_hexes_with_Los` → `validHexes`.
4. `_form_sub_Fire_Groups(firegroupUnits, validHexes)` → `subFGsArray`.
5. `_drawLOS` + `flashHitPoints`.
6. `switch (phase)`: per-phase loop через sub-FG с вызовом `Rules.fireAttack` (переименовано с `defensiveFF`).
7. `_set_firing_Status(phase, firegroupUnits, weaponsKeepingRoF)` — финализация firingStatus / prepFired / advFired.

### Multi-hex FG + splitting
- `Rules.filter_hexes_with_Los(hexes, target, orchardInSeason)` — фильтр по LoS + hindrance < 6.
- `Rules.array_of_adjacent_Hexes_arrays(hexes)` — BFS-разбиение на adjacency-компоненты.

### ELR (5.1)
- `State.elr = { german: 3, soviet: 3 }` (init state.js).
- `unit.elr` присваивается в createAndLoadUnits (elr = 20 если нет lowerQuality).
- `_processMC` → `quality_reduce` / `reduce_then_quality` при fail > ELR.
- Engine handler `_apply_changes_for_targets` обрабатывает replace_unit chain.

### Smoke (3.3.1)
- **Terrain overlay:** `State.dynamicTerrain = { "col,row": ['smoke'] }`. `cards.terrainAt` мержит static + dynamic.
- DRM: through/into = +2, out of = +1.
- Placement two-step (own = 1 MF, adjacent = 2 MF), dr per unit + CX drm.
- Movement cost +1 MF при входе. Road bonus loss.
- Render: 8 puff'ов Konva.Animation.

### LOS (pixel-based, terrainLOS.js)
- Bresenham + pixel-set obstacle check (woods/buildings/hills/orchard/brush/roads).
- Card metadata (xOffset/yOffset/rotation) в JSON.
- **In-season orchard** блокирует LoS между разными elevation (правило: shooter/target на разных hills → orchard = obstacle).
- `checkLOS(fromHex, toHex, orchardInSeason)`.
- Orchard-Road shield (`_los_stays_on_road_in_Orchard`) с дедуп-логом.

### Height Advantage
- `Rules.calcHeightAdvantage` — HA +1 если target выше, TEM=0, стрелок ниже.
- Exception: crestLine hexside match с move-crest.

### Woods-Road TEM
- `calcTEM(hex, hexUnits)` — если Woods-Road hex + юнит с `usedWoodsRoad=true` → TEM = forest (1).
- Автоматически ставится при UseWoods в MPh и при rout-move в Woods-Road (авто-treat as woods).

### Turnphase крутилка
- `./graf/turnphase.gif` — 8-гранный диск с названиями фаз.
- Отрисован на uiLayer через `UIState.addImage`, `scale: 0.8`, `opacity: 0.5`.
- `UIState.rotateImage('turnphase', -45)` при NextPhase (CCW, 45° = 1 грань).

### Визуал юнитов (renderer.js)
- CX text, pin, DM+4, wound, first fire, FF big text.
- **`pfText`** ("PF" оранжевый центр) — prepFired.
- **`afRect`/`afText`** ("fired" белая полоска снизу) — advFired.
- **`mustRoutRect`** (красная пунктирная рамка) — mustRout.
- **`inRoutingRect`** (жёлтая рамка) — активный router.
- flipRendering/flipReplaceUnit анимации для broken/reduce/quality_reduce.
- Renderer читает target position из `unit.x` — избегает race с pos-tween.

### `isSameHex(a, b)` helper — hexUtils
Заменяет 16 повторов `a.col === b.col && a.row === b.row`.
